# Student Management System:

## What is student management system: 
STUDENT MANAGEMENT SYSTEM is a python command-line student management system(Duhh) which is built for
a fictional institute.It can be used in any institute like colleges, schools,  universities e.t.c. to add,
view, update, search, delete students(also their age and marks).And keeps the records permanently in 
`RECORD.txt`
